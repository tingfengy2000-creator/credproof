# Local model repair records

These are sanitized records from the local Qwen-Agent/Ollama bridge. `success` completed one candidate and trusted verification; `rpc3` is retained as an incomplete/failed feedback run. Synthetic credentials are replaced by `[SYNTHETIC_CREDENTIAL]`. The model trace is evidence of that run, not a replay or a guarantee of general repair ability. Model weights and the Ollama service remain outside this repository.
