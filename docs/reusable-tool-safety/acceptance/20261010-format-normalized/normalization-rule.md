# 固定规则：credproof.python-outer-fence/v1

本规则在事后动态验收前固定；只处理已有输出，不恢复原任务或模型额度。

1. 输入为非空字符串，UTF-8最多65,536 bytes，无NUL。原本为纯Python源码时保持全部原文，包括空白和字符串中的反引号。语法错误不修复。
2. 仅当整个字段为一个完整外层三反引号块时去掉包装；语言标记只接受空、`python`、`py`，区分大小写。开闭标记各占一行，外围只能有空白，内部不得有第二个或含混的独立围栏。
3. 只删除开标记及之前包装空白、闭标记及之后包装空白。开闭标记之间的正文原样保留，包含所有缩进、内部空行、字符串和行尾。记录两个精确删除区间、原文、UTF-8摘要及差异。禁止全局删除反引号、选取代码块、补括号、改变量/导入/参数或逻辑。
4. 不支持的格式为`OUTPUT_FORMAT_UNSUPPORTED`，停止。格式成立后做有大小上限的AST及编译检查；只编译，不导入或执行。语法失败即停止。
5. 语法通过只允许一次原规则的`check_project`隔离验收。记录`POSTHOC_FORMAT_NORMALIZED_RECHECK`，新增模型调用0。原模型任务的UNKNOWN和原始响应/候选完全不变。

若事后验收FAIL/UNKNOWN，保留结果并停止，不修改现有安装版解析流程或派生业务源码。仅取得PASS及同对象公开取件复检证据后，才按本轮授权将规则接入统一候选解析入口并做历史响应协议回放；不能把回放记为新推理。
