# 本地 Agent 小试验结果

2026-09-29。结论：**本地模型确实进行了多步工具调用，并修好了限定的运行时泄露；没有证明反馈 Agent 比合理固定流程或一次性模型更能修复。暂不据此全面改换产品主线。** 本次仅保留本地试验分支，不推送、不发布，原版本继续保留。

## 运行环境与真正离线的证据

- Qwen-Agent `0.0.34` 的官方 Assistant 工具循环，Ollama `0.34.4`；Qwen3-Coder `30.5B`，GGUF `Q4_K_M`。
- 模型 manifest digest：`06c1097efce0431c2045fe7b2e5108366e43bee1b4603a7aded8f21689e90bca`；权重 blob SHA256：`1194192cf2a187eb02722edcc3f77b11d21f537048ce04b67ccf8ba78863006a`。模型/依赖来源及校验见 [validation](validation)。官方 config 的 size 元数据为 539，实际完整对象 542 字节，但官方 SHA 完全匹配；该差异记录于 model-download.json，没有跳过校验。
- RTX 5090、WSL Ubuntu 24.04、Python 3.12.3；实际模型上下文 16384，第二轮最大报告输入 5173 token。2 秒采样的显存最高 **19176 MiB（约 18.73 GiB）**，最低剩余 13012 MiB；采样值不是连续测得的绝对峰值。
- [模型服务与控制器的 network namespace](../../experiments/local-agent-pilot/records/20260929t080000z-offline-02/namespace-membership.json)相同；运行前后仅 `lo`，无外部 IPv4 路由，IPv4/IPv6 外连测试均失败。`OLLAMA_NO_CLOUD=1` 且服务日志确认 `Ollama cloud disabled: true`。这包含三例正常结束的漏洞 Agent 任务及 p06 正常任务，不只是 localhost 配置。
- 随机依赖握手两轮均真实通过，每轮 3 次模型调用；未知工具、错误参数、额外参数和越界路径的程序测试均拒绝。程序负测未计作模型工具使用。
- 第二轮监督命令 exit 0；握手 1.536 秒，完整六例及 D 比较 155.361 秒。记录中的 `complete` 是命令收集完成，不掩盖 p01 的 STOPPED_LIMIT。前后源码冻结哈希一致，服务日志未见非零截断事件；本轮可提交记录未发现完整运行时合成凭据。
- **作品本次运行未调用付费 API。** 下载属于联网准备；推理在局部网络限制下完成。没有修改全机防火墙/代理、挂载用户目录给候选或阻断 Codex。硬件、电力与开发订阅不属于“零成本”。

## 能归因于什么，下一步是否继续

模型实际完成了读代码、选择触发输入、解释观测、生成补丁和继续调用验证工具。触发执行、精确凭据匹配、通道规则、隔离、最终 PASS/FAIL/UNKNOWN、证据脱敏与记录由固定程序完成。候选和裁判职责分离，不能把程序检查的正确性归功于模型。

新增工程内容是受限运行时凭据通道检查、可追踪的工具反馈与修复提案、隔离和固定裁判；复用了官方模型、推理服务、Qwen-Agent 工具循环与 bubblewrap。原 CredProof 静态检测及验收代码和实验保留，但本轮没有硬套静态扫描器去判断运行时泄露。项目代码由 Codex 辅助开发；标为模型候选的代码均有真实本地请求/响应来源。

建议保留为有证据的支线原型，**暂不全面转向 Agent 产品**。最小调整是先约束正常误报导致的无谓修改，并在完整复验通过后及时收束任务；若继续，冻结后用少量新结构案例核查是否出现固定规则或一次性修复做不到的价值。本轮不追加调优重跑去追求全绿。

仍缺：独立留出与重复稳定性；失败补丁反馈后改进的真实样本；可靠的正常诊断与预算终止；超出明确明文泄露形式的覆盖。候选与采集器共享解释器，不能宣称对任意恶意 Python 防篡改；尚未验收任意真实项目、提示注入全面防御或跨平台部署。普通哈希不构成第三方证明。本轮不是初赛完成版或外部验收。
