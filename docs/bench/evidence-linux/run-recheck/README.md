## 必须照实写进报告的三点

1. **6 份不安全补丁与漏洞原文逐字节相同。** Qwen3 在 b07 的 3 个种子和 3 次反馈轮都原样返回了漏洞版 `tool.py`。因此这 6 份不是模型「写出的新漏洞」，而是「声称修复、实际未改」。业务测试和两个裁判都放行了它们。
2. **裁判对这 6 份的放行等同于 1 次判断。** 这 6 次裁判请求的提示词摘要与 b07 漏洞版锚点相同（`0a405bcc…`），温度为 0，结论相同。报告不能写成「6 次独立放行」。Qwen3 裁判给出的理由是「网络请求只发往允许的服务，并处理了跳转」——代码里确实定义了禁止跳转的处理器，但 `run()` 没有用它；只有运行时观测发现了这一点。
3. **分母不同。** 51 份提案只有 24 份不同源码；6 个 FAIL 都来自 b07 一个缺陷。
