# 设计产物检查

本目录验证对象是离线方案阅读页和使用模拟数据的界面原型；不是后端业务、模型推理或竞赛实验的验收结果。

本次使用本机 Chrome 和 Playwright 检查：

- 五个页面在 1440、768、390、320 像素宽度下的文档横向溢出。
- 发现搜索、空结果、历史未扫描、来源标签方向键和移动菜单。
- PASS、FAIL、UNKNOWN 切换后，AI 展示视角、报告与总览保持同一验证状态。
- 模拟导出说明、Esc 关闭和重置演示。
- 整合阅读页的五章、七张图片、内部锚点和本地文件链接。
- 浏览器脚本错误和外部 HTTP 请求均为零。

`validation.json` 保存分项记录。截图采用减少动画模式，避免将淡入半程误当最终颜色。总览、验证页、移动页及七张架构图另外经过人工视觉检查。

不据此声称完整无障碍认证、所有浏览器兼容、真实凭据检测质量、修复正确性或模型效果；这些将在方案批准后的业务实现中另行验证。
