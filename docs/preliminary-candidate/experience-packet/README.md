# 开发者体验包

这是一个供 2—3 位未参与开发者执行的**探索性可用性体验材料**，不是已完成的用户研究，也不是性能或满意度实验。体验目标是看参与者能否沿着现有作品入口完成一次证据判断、补丁验收和独立复检。

## 体验任务

- 找到凭据进入禁止输出通道的依据；
- 判断一份候选补丁是否合格，并说明依据；
- 完成或理解一次独立复检；
- 说出仍未验证的范围。

复用 h01、h03、h07 和材料复检，不新增案例或模型任务。安装准备时间与任务时间分开记录；不要求参与者接触真实凭据。
