# 参与者任务单

## 说明

你将使用 CredProof 的本地演示材料判断三个受控 Python 案例。案例只使用合成凭据或脱敏回放，不需要登录任何账户。请把“看到的证据”和“自己的判断”分开写。

## 任务一 找到泄露依据

打开 h01。指出：

- 凭据从哪里进入不应接收秘密的输出通道；
- 哪一条执行证据支持你的判断；
- 哪个业务行为仍必须保留。

## 任务二 判断候选补丁

打开 h03 的候选1和候选2。分别回答：

- 候选1是否合格，为什么；
- 候选2改变了什么；
- 你依据的是模型解释、程序结果，还是代码和输出证据。

## 任务三 理解独立复检

打开 h07 或一份材料复检入口，说明：

- 当前对象是否仍与旧报告对应；
- 新复检实际执行了什么；
- 如果必要材料缺失，你会把结论记为 PASS、FAIL 还是 UNKNOWN，为什么。

## 任务四 说出边界

写出你认为本作品目前不能证明的一件事，例如任意代码库泛化、真实凭据撤销、跨机器部署或人工效率提升。
