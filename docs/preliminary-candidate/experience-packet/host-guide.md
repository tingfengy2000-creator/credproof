# 主持人操作说明

## 准备

1. 在工作区运行 `python -m agent_pilot.launch --demo --mode view`，使用历史回放入口；不启动模型，不把回放当作现场推理。
2. 如需展示复检，使用已经准备好的隔离环境运行 recheck 入口；没有隔离时停止动态执行，不在宿主机运行候选。
3. 给参与者[任务单](task-sheet.md)和空白记录表。说明不收集真实凭据、账号或与任务无关的个人信息。
4. 分别记录环境准备时间和任务开始后的实际时间。不要提示答案，不替参与者解释 h03 根因。

## 引导规则

- 可以重复解释页面操作，不解释判断结论；每次求助记录问题和时间。
- 若参与者把模型解释当成证据，追问“页面上的哪一条实际执行结果支持它”。
- 若参与者认为脱敏前缀足够，要求重新查看候选1的输出和值检测。
- 若复检被环境阻断，记录为环境阻断，不把参与者任务记为失败，也不把阻断改写成 UNKNOWN 的安全结论。

## 结束

收回记录表，标注是否完成、误判、求助次数、环境阻断和实际用时。只有参与者明确同意后才保留匿名编号；不记录姓名、联系方式、真实代码或凭据。

## 记录口径

本包目前没有任何已完成参与者数据。之后若真的执行，另建带日期的记录目录；不得把一次体验写成统计显著性结论，也不得与原八例模型成绩拼接。
