## 原报告模板的明确要求

| 项目 | 原件要求及落地方式 |
|---|---|
| 完整性 | 作品应为基本完整设计，报告清晰说明或图示方案；不能只交架构图。 |
| 纸张与正文 | A4；除标题外，全部内容宋体、小四号、1.5 倍行距。标题精确字号未在填写说明中规定，不自行声称官方要求某字号。 |
| 填写说明页 | 原件要求删除各项目的说明文字，但明确保留填写说明页。最终应删除各章括号提示和示例文献，保留本页。 |
| 匿名 | 报告避免学校、院系、指导教师等身份信息。截图、图例、路径、窗口标题、文档作者与批注属性也需检查，不能只看正文文字。 |
| 封面 | 本地模板只有作品名称、提交日期两项；名称已拟，提交日期待填。不向匿名封面添加队员/学校/导师信息。 |
| 摘要 | 限 500 字以内，涵盖动机、功能、特性、创新与实用性；本稿提供约 300 字摘要。 |
| 原始章序 | 摘要；第一章作品概述；第二章作品设计与实现；第三章作品测试与分析；第四章创新性说明；第五章总结；参考文献。 |
| 结构调整 | 模板允许增加内容或微调结构。本稿保持原章序：应用场景置第一章，实现与信任边界置第二章，数据边界置第三章，后续计划置第五章。 |
| 页数 | 原件页脚的“共 7 页”是模板预置页码，不是已找到的篇幅上限；导出时更新目录、页码和总页数。 |
| 参考文献 | 原件提示参考 GB/T 7714-2015；应替换为真实使用来源，不能保留模板样例冒充引用。 |
