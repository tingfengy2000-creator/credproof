# 真实界面演示视频

本目录提供 `credproof-demo-3min.mp4`（180 秒）和从同一批原始画面剪出的 `credproof-demo-1min.mp4`（60 秒）。均为字幕版，无配音。

画面由实际浏览器页面约每 0.5 秒采集一帧，再编码为视频；属于低帧率界面实录剪辑，不是伪造页面、连续桌面高帧率录屏或新一轮模型推理。页面内容没有重绘或替换，只在画面外增加标题和字幕。不同镜头之间的操作准备间隔已剪去；同一镜头内按记录时间采样，没有把模型等待伪造成快速推理。

顺序为首页 → 三例入口 → h01 → h03 失败候选 → h03 修正候选 → h07 → **本次点击重新验收并得到新结果** → 收尾。前三例持续标识真实历史回放。新复检是固定程序执行，不调用模型；页面显示 2026-10-03 的新时间、当前候选摘要、INTACT 与 PASS。实际 h07 复检 JSON 另存于本版检查目录，可核对画面。

Twine 外部案例作为说明书和答辩补充，没有塞入三分钟主线。原完整批次 C 的问题修复 4/4 与完整任务 6/8 口径继续保留。

`capture-manifest.json` 记录实际帧的时间、顺序与 SHA256；原始 PNG 素材保留在本机独立制作目录，不用重复的大量帧增加候选包体积。`video-receipt.json` 记录编码命令、源代码版本、剪辑区间、输出尺寸与校验值。使用 `scripts/encode-demo-video.py <raw-frame-folder> <new-output-folder>` 可从保留的原始帧重新编码；此命令不控制浏览器，也不能代替真实录制。素材采集草稿与时间修正前的片段未用于成片。

观看以成片为准；讲解要点见 [讲稿](../demo-script.md) 和 [源码讲解](../source-walkthrough.md)。这两段视频供候选展示打磨，不代表比赛平台已接收或获奖能力已验证。
