# 三分钟：AI辅助修复、程序验收、人工采纳

作品：密证 CredProof——面向Python工具的AI辅助安全修复与证据验收工作台。

## 0:00–0:35 问题和对象
首页→资料助手→人审区。“工具能跑不代表只做了允许的事。检查凭据输出、目录越界和未授权请求，同时保留真实文件读取和服务认证。”

## 0:35–1:15 AI候选不是批准
打开历史候选并强调回放：“模型代码缺少os导入，错误转换HTTPError。原FAIL和必要测试1通过3失败保留；提前报错不是安全修好。程序禁止采纳为已验证修复，仍允许导出诊断。”

## 1:15–2:00 开发者修订与新验收
打开v001相邻差异：“这是开发者修订、Codex辅助，恢复导入并直接使用固定访问组件，保留异常约定和真实业务。新版本必须重验。”展示4必要测试实际通过、0跳过，正常返回和允许文件＋越界跳转两个独立场景；正式对象PASS/PENDING。

## 2:00–2:40 采纳和复检
展示单独标识的审批功能测试：“PASS不会自动采纳；可以拒绝PASS，不能批准FAIL。确认及导出重新核对对象、规则、测试、组件、报告。测试批准不是本人签字，正式对象仍待本人审阅。”打开同对象公开取件后的新目录复检依据。

## 2:40–3:00 结果
“AI提出建议，开发者修订，程序独立验收，人决定采纳。交付具体版本、差异和可再次运行的依据，原仓库未自动应用。本轮没有新模型调用，开发者修订不算模型自动成功。”
