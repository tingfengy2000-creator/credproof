# 答辩问答：AI辅助人审范围

**与扫描器、CI或现成修复Agent有什么区别？**
扫描和CI已有检测/测试能力，与本项目有重合。作品把已登记Python工具的真实安全触发、AI建议、开发者差异修订、固定安全/业务验收、独立采纳及同对象复检接成可操作流程。不宣称通用Agent或新算法。

**固定规则和人工也能处理，为什么仍有用？**
人仍要定义范围、适配接口及必要行为。模型辅助提出建议，程序统一执行检查和保存依据，开发者可继续修对失败候选。没有测量节时和成本收益，不填效率数字。

**真正新增了什么，证据在哪里？**
credproof_safety/human_review.py保存新版本、父关系、来源、绑定和追加决策；web.py实施会话/登记；project.py与runner.py执行三类观察及必要业务检查。当前评审入口提供浏览器修订、完整PASS与公开取件复检，测试批准和正式PENDING分开。

**模型或人改错怎么办？**
同一检查器照样FAIL/UNKNOWN；人不能覆盖技术结果。必要测试不执行、缺材料或对象变化都不能作为已验证修复采纳。重新验收不自动恢复旧批准。

**支持范围和归属？**
已适配、授权的Python工具、合成凭据和受控服务，既有WSL/bubblewrap。模型、Qwen-Agent、Ollama、pytest注明来源，团队实现访问组件、适配、检查和工作台。Codex辅助开发者修订不是作品运行时模型修好。全自动效果仍未完成，经用户批准移出当前必需范围；AI辅助开发参赛许可由本人确认。
