# 密证 CredProof 查看说明

Windows：完整解压后双击 `start-credproof.cmd`。随包 Python 3.12.10，不需要安装 Python、虚拟环境、WSL 或模型。浏览器自动打开实际本地地址；关闭时在启动窗口按 Ctrl+C。若临时目录不可写，请检查系统 TEMP 权限；不要只复制启动文件。

默认入口直接运行随包 Python，不依赖 PowerShell，也不绕过系统执行策略。若运行时缺失则尝试系统解释器；学校策略阻止此后备入口时，请重新解压完整交付包，无需调整安全策略。

推荐查看：概览 → 补丁记录与报告 → 人工审阅 → h03 案例回放。所有既有记录均为历史，不是打开页面后新推理。人工审阅初始为程序 PASS、人工 PENDING、原件 NOT_APPLIED；v000 保留 AI 原件 FAIL，v001 是开发者修订。程序通过不等于本人采纳。

每次启动重新创建临时审阅副本，正常退出清理。强制关窗留下的带 owner 标记副本会在下次启动确认原进程已退出后清理；运行中的实例、不明确和无标记目录不删除。查看模式中的编辑、决定、静态导出仅操作该副本；动态验收被后端拒绝。无需替作者采纳任何补丁。

重新验收需要已准备且预检通过的受控 WSL/bubblewrap 环境和业务测试依赖；现场修复还需要固定本地模型及可信安装解释器。此查看包不携带这些环境。缺环境会显示阻断原因，没有宿主执行或付费 API 回退。开发者可从同版本程序安装 wheel，用 `python -I -m agent_pilot.launch --workspace <材料目录> --demo --mode view` 查看材料。

macOS/Linux 需要预装 Python ≥3.11，可运行 `sh start-credproof.sh`；这不是跨系统动态安全验收声明。

哈希用于核对文件和对象，不是第三方签名或绝对安全证明。冻结 bench 数据按完整批次展示；历史成功/失败不合并为新的模型成绩。
